Get a skill working in three steps

Connect Loomi Connect, add the skills, then ask in your own words.

You need
  • Your Loomi Connect server URL. Ask your Bloomreach admin; each region has its own.
  • A Bloomreach login with access to the projects you want to use.

  1. Connect Loomi Connect

    In a terminal, with your URL in place of the brackets:

    claude mcp add --transport http loomi-connect <your Loomi Connect URL>

    Then start claude, type /mcp, and sign in.

  2. Add the skills

    In Claude Code, paste:

    /plugin marketplace add bloomreach/loomi-connect-community
/plugin install loomi-engagement@loomi-connect-community
/plugin install loomi-discovery@loomi-connect-community
/plugin install loomi-platform@loomi-connect-community
/plugin install loomi-product-data@loomi-connect-community

  3. Ask

    "Using Loomi Connect, list my Bloomreach organisations and projects."

    That checks the connection. Then ask for real work, for example "Give me this week's ecommerce briefing". Claude picks the right skill.

  1. Connect Loomi Connect

    In claude.ai or Claude Desktop, go to Settings → Connectors, add a custom connector with your Loomi Connect URL, and sign in.

    If you can't add connectors, your organisation admin needs to allow it.

  2. Add a skill

    Download a skill's .zip from the skills page. Then go to Settings → Capabilities → Skills and upload it.

    Not sure which? Start with loomi-project-overview.zip.

  3. Ask

    "Using Loomi Connect, give me an overview of my project."

    Claude uses the skill when your request matches it.

  1. Connect Loomi Connect

    In a terminal, with your URL in place of the brackets:

    codex mcp add loomi-connect --url <your Loomi Connect URL>
codex mcp login loomi-connect

  2. Add the skills

    codex plugin marketplace add bloomreach/loomi-connect-community

    Then install loomi-engagement, loomi-discovery, loomi-platform and loomi-product-data from Codex's plugin directory.

  3. Ask

    "Using Loomi Connect, list my Bloomreach organisations and projects."

    Codex picks the right skill. To call one by name, type $ and the skill name.

  1. Connect Loomi Connect

    Turn on developer mode in Settings → Apps & Connectors → Advanced. Then go to Plugins → + → Add custom MCP server, enter your Loomi Connect URL, choose OAuth, and sign in.

    Developer mode depends on your plan and your workspace admin.

  2. Add a skill

    Download a skill's .zip from the skills page. Then go to Skills → Create → Upload from your computer.

    Skills are on ChatGPT work plans; your workspace admin turns them on. Not sure which skill? Start with loomi-project-overview.zip.

  3. Ask

    "Using Loomi Connect, give me an overview of my project."

    Or type @ and the skill name to call it directly.

Stuck? See connecting Loomi Connect for every client and common errors. Skills that change data always show you the change and wait for a yes.
