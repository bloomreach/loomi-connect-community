# Discovery search health check

Summarises search performance for a Bloomreach Discovery site, picks out queries worth investigating, and suggests next steps without changing anything.

| | |
|---|---|
| **Products** | Discovery |
| **Access** | Read-only |
| **Loomi Connect tools** | `list_discovery_accounts`, `list_discovery_sites`, `get_discovery_overall_performance`, `get_discovery_search_performance`, `get_discovery_query_performance`, `search_discovery_product_grid_insights` |
| **Tested with** | Not yet tested; please add your results |
| **Maintainer** | Bloomreach |

## Example prompts

- "How is site search doing this month?"
- "Which search queries are underperforming?"
- "Run a search health check on our Discovery site."
